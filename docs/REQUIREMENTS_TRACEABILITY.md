# Member 3 requirements assessment

Scope: authentication, account lockout, password reset, task assignment,
administration, and security auditing, as owned by Member 3 in the shared
contract. The same rules as above apply: a requirement is only marked
verified where a test or recorded run shows it.

Evidence basis. All test evidence below comes from automated backend tests
that use in-memory fakes or a fake database pool (`backend/tests/`); the
current checkout ran 196 backend tests with 0 failures on 2026-11-03. The
live disposable-MySQL run of 2026-10-27 predates the lockout, audit, admin,
password-reset, rate-limit, and assignment code, so none of those features has
live database evidence yet. The guarded `npm run test:mysql` script has not
been run for them. The frontend has registration and sign-in screens only;
there is no frontend for password reset, administration, or assignment.
