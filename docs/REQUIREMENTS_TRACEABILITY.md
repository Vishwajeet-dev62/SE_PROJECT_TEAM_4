# Member 3 requirements assessment

Scope: authentication, account lockout, password reset, task assignment,
administration, and security auditing, as owned by Member 3 in the shared
contract. The same rules as above apply: a requirement is only marked
verified where a test or recorded run shows it.

Evidence basis (checked 2026-11-15):

- Backend: 300 automated tests pass (`npm test --prefix backend`), mostly with
  in-memory fakes or a fake database pool.
- Frontend: 61 tests in 13 files pass (`npx vitest run`); lint and the
  production build pass.
- Live database: Member 3 ran `npm run test:mysql` and
  `npm run test:mysql:member3` against a local disposable MySQL database named
  `task_manager_test`, built from all migrations, on 2026-11-15. Both ended
  with `"result":"passed"` and verified cleanup. The Member 3 script
  (`backend/scripts/mysql-integration-member3.js`) covers registration, bcrypt
  cost, lockout, administration including account creation, password reset
  including ended sessions, assignment and the task-update guard, one-year
  audit retention, rate limiting, and audit-log hygiene.
- Earlier live runs found and fixed two defects that the fake-database tests
  could not show: accounts locked after 4 failed logins instead of 5, and the
  live script read a migration-history column that no longer existed.
- Not verified: no real email has been sent by any test (the SMTP sender is
  tested with a fake transport only), and nothing has run behind a real proxy
  or across several server instances.
